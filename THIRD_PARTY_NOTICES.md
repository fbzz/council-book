# Third-party notices

The public site (`site/`) adapts material from the projects below. No third-party code runs on the
site: there is no JavaScript, and nothing is fetched from another origin. Only visual values
(colours, spacing, radii, type sizes) and icon outlines were translated into the site's own
stylesheet (`site/static/style.css`) and icon data (`site/data/icons.json`).

## OpenSourceUI

The site's interface styles (dark surfaces, table, stat-tile, terminal-log, alert-banner and
progress-ring looks) are adapted from OpenSourceUI (https://opensourceui.in), a React and
Tailwind CSS component library, translated into plain CSS.
